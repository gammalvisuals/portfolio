# Gammal Visuals — موقع البورتفوليو

الموقع الشغال: **https://gammalvisuals.github.io/portfolio/**

## إزاي تضيف شغلك على الموقع (من غير أي كود)

1. افتح فولدر **`works/`** من اللينك ده: https://github.com/gammalvisuals/portfolio/tree/main/works
2. دوس **Add file** (فوق على اليمين) وبعدين **Upload files**.
3. ارفع الصورة، وبعدين **غيّر اسمها** للصيغة دي:

   `القسم__اسم-الشغل.jpg`

   الأقسام المتاحة:
   | القسم | بيظهر فين |
   |-------|-----------|
   | `social` | Social media |
   | `ads` | Advertising |
   | `print` | Print & packaging |
   | `logos` | Logos & branding |

   مثال: `social__kampanyia-orange.jpg`
4. دوس **Commit changes** الأخضر.
5. بعد دقيقة أو اتنين الصورة هتظهر لوحدها على الموقع في القسم الصح.

> ملحوظة: امسح كلمة `README.txt` من اسم الملف لو ظهرت أثناء الرفع.

## إزاي تعدّل نصوص الموقع (الاسم، رقم الواتساب، الإيميل)

- افتح ملف **`index.html`** ودوس على علامة القلم (Edit).
- في أول جزء من الكود هتلاقي `SITE = { ... }` — عدّل القيم اللي جواه بس، وبعدين Commit changes.
- أي حاجة تانية ابعت لـ Instinct وأنا أظبطهالك.
